## **Medsoft Web**
Frontend application for Medsoft - a modern medical management platform for clinics and healthcare teams.

This Angular application provides a clean, responsive UI for managing patients, appointments, consultations, billing and administrative workflows.

---

## **FEATURES**

- Authentication & Role-Based Access.
- Dashboard with Daily Overview.
- Patient Management.
- Appointment Scheduling (Calendar View).
- Consultation & Prescription Workflows.
- Billing & Reports.
- Admin Panel (Users, Roles, Settings).

---

## Tech Stack

- Angular 17
- Angular Material
- RxJS
- SCSS
- Signals
- Chart.js
